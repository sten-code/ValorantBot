# Mouse USB Host Shield

## Uploading the firmware
Go into the Arduino IDE and install these Arduino Libraries:
- [HID-Project](https://github.com/NicoHood/HID) by [NicoHood](https://github.com/NicoHood)
- [USB Host Shield Library 2.0](https://github.com/felis/USB_Host_Shield_2.0) by [Oleg Mazurov](https://github.com/felis).

Open the `mouse_usb_host_shield.ino` file in the IDE and upload it to the Arduino.
